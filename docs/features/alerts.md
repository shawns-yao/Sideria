# 告警与通知

更新日期：2026-10-06  
状态：设计阶段，尚未实现和验证

## 范围

告警覆盖 Agent 失联、磁盘空间不足、持续资源异常和指定容器停止。后续增加应用健康与 Kubernetes 异常，必须以对应采集能力为前提。

规则明确对象、阈值、持续时间、数据新鲜度、重复通知间隔与恢复条件。瞬时峰值不直接等同于持续异常；数据缺失单独处理，不当成零值恢复。

## AI 与告警

阈值规则和通知发送由确定性逻辑执行，不依赖每次模型调用。AI 可在用户发起分析时解释告警、关联现有证据和建议下一步，不能擅自改阈值或自动修复。

主动周期性 AI 分析不是首版默认行为，启用前需要明确触发条件、数据范围和成本上限。

## 阶段与验收

完整告警与通知在持续运维阶段实现。验证触发、持续、重复抑制、恢复、采集缺失和通知失败；关闭浏览器后仍按规则运行。通知渠道与保留期待确认。
