# 系统服务与软件安装

更新日期：2026-10-06  
状态：设计阶段，尚未实现和验证

软件安装采用明确模板，限定支持的系统、架构、版本和安装源。执行前检查已有安装、目录、权限、磁盘、端口及必要网络访问。配置修改应有备份和可审查差异，区分保存配置与重启服务。安装失败不承诺自动回滚所有副作用。

## 系统服务

报告当前系统服务管理能力，支持后续查询、启停与重启；非支持系统返回明确不可用原因。执行用户、提权要求及服务名称约束由 Action 定义，不能静默转成任意 Shell。

## 安装任务

用户选择主机、模板和版本 → 检查环境 → 生成具体步骤 → 权限与必要审批 → Agent 执行 → 验证安装版本、服务状态和任务结果。

任务记录每一步及失败原因，重连后查询执行事实，不自动重复有副作用的安装。模板涉及的包源、代理与凭据引用须明确，不能假定所有服务器共享配置。

## 阶段与验收

软件安装与完整服务管理在 MVP 后按模板逐项开放。测试覆盖已安装版本、权限不足、磁盘不足、依赖下载失败、部分成功和中心断线。配置恢复、卸载和业务数据删除不能被混成通用“回滚”。
