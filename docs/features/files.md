# 文件目录与传输

更新日期：2026-10-06  
状态：设计阶段，尚未实现和验证

- 目录浏览、路径跳转、隐藏文件、属性、权限、属主和软链接。
- 文本预览、上传下载；编辑、移动和删除按后续阶段逐项开放。
- 大目录按批读取，文件预览限制大小；目录大小和递归搜索按需执行。
- 文件操作使用文件系统 API，不将用户路径直接拼接进 shell。
- 编辑保存前核对版本或文件摘要，检测外部修改；保存失败不破坏原文件。

## 执行与传输

目录和文本读取采用轻量请求，文件传输采用可追踪的后台任务与独立数据流。路径校验、符号链接处理和权限必须在 Agent 端落实，前端限制不构成权限边界。

读取权限与“允许将内容发给模型”分别判断；凭据、环境文件和敏感业务数据不能因用户有浏览权限就默认进入模型上下文。

## 首版与后续

MVP 支持浏览、受限文本预览、上传下载。上传新增文件也需要写权限；覆盖已有文件须检测目标变化并按策略确认，不能绕过后续编辑能力的保护。

完整在线编辑、版本快照、移动和删除后续开放，见[配置修改与回滚](configuration.md)。

## 验收

覆盖不存在目录、无权限、软链接、大文件、特殊文件名和中途断线；核对上传下载内容与目标主机身份。递归大小统计限制范围、并发和执行时长。
