# 统一工具与通信

更新日期：2026-10-06  
状态：设计阶段，尚未实现和验证

## 通信与会话

| 通道 | 用途 | 约束 |
| --- | --- | --- |
| HTTPS | 注册、升级包、独立文件传输 | 认证、TLS 校验、长度和超时限制 |
| Agent 主动长连接，建议 WSS | 心跳、指标、任务、状态、终端及日志消息 | 消息大小限制、背压、心跳优先、断线重连 |
| 浏览器 WebSocket | 实时页面、终端输入输出、任务日志 | 用户会话与服务器权限校验 |
| 集群连接器主动长连接 | 集群资源变化和操作结果 | 独立连接器身份与集群作用域 |

采用 WSS 时建议初版控制消息使用 JSON。应用协议包含版本、消息类型、请求或任务 ID、时间及结构化内容；具体编码随传输选型确认。终端和日志会话带独立会话 ID；高流量会话应可拆成独立连接，不能阻塞控制消息。

文件上传下载通过独立 HTTPS 数据流完成。中心签发绑定节点、任务、方向和有效期的传输凭据，由 Agent 主动建立传输。中心流式转发，不默认缓存整个文件。文件操作仍校验目标路径、权限和任务归属。

重连采用退避策略和随机抖动。缓存、队列和日志必须有上限；溢出时报告数据缺口，不能无限消耗内存或磁盘。

## 结构化 Action

工具按能力注册，普通功能优先调用文件系统 API、Docker Engine API 或明确的系统接口，不将所有操作转换成 Shell。候选 Action 包括：

| Action | 职责 |
| --- | --- |
| `file.read` | 读取受授权范围内的文件 |
| `file.write` | 按版本检查、变更差异和快照流程保存文件 |
| `docker.logs` | 查询指定容器日志 |
| `docker.restart` | 重启指定容器 |
| `system.service.restart` | 重启指定系统服务 |
| `shell.exec` | 在明确授权下执行无法由现有工具表达的命令 |

以上为工具命名方向，不代表已经实现的接口。每个工具需声明参数约束、能力要求、操作影响、提权要求、超时、结果格式及重试条件。

后台任务下发消息包含 Task、Step、目标执行和 Attempt 的关联标识；普通查询使用 Request ID，会话使用 Session ID。消息携带相应 Action、参数、截止时间和执行授权，不为每次查询强制创建多步骤任务。Agent 校验认证身份与实际目标，不仅信任自报的目标 ID。消息确认区分已接收、已开始和已结束；收到消息的确认不等于操作已经执行。

Shell 保留为兜底能力，网页终端也属于任意命令执行入口。不能仅凭命令名称将其判定为只读；需要明确会话或命令级授权范围，不能成为绕过结构化工具权限的通道。

## 执行结果与重连同步

结果需包含执行状态、阶段、退出结果或结构化错误、时间和日志引用。Agent 保留目标执行与尝试记录，重连后同步未确认结果。协议兼容、能力变化、重复消息和日志缺口均返回明确状态，不能静默降级为无约束 Shell。

## 请求类型与统一检查

UI 与 AI 共用工具定义、参数校验、权限检查、结果结构和必要审计；共用检查不意味着共用全部持久化生命周期。

| 类型 | 示例 | 执行与记录 |
| --- | --- | --- |
| 查询请求 | 目录列表、当前状态、最近日志 | 轻量请求、Request ID、超时和必要审计；AI 调查可关联 Analysis ID |
| 持续上报 | 指标、心跳、能力变化 | 有界采集与接收通道，不为每次上报生成 Task |
| 交互会话 | 终端、日志跟随 | Session ID、身份、目标、有效期、断开和关闭记录 |
| 后台任务 | 文件传输、安装、部署、配置修改、容器重启 | Task、步骤、目标执行与 Attempt；保存进度和结果 |

高成本读取可以作为可取消的后台任务执行，但操作影响仍是读取，不能因为进入 Task 就取得修改权限。具体映射按 Action 定义。

## 待确认

WSS/gRPC、消息大小、会话流量隔离、确认语义、兼容窗口和缓存上限仍需在实现前确定。协议、字段和 Action 名称目前是设计方向。
