# 功能页面与参考图取舍

更新日期：2026-10-06

用户提供的八张新概念图用于信息结构参考，不自动扩大 MVP。图片中的文字、数量、连接线和示例操作不是已实现能力。共同视觉规范见 [UI 设计](ui.md)，前端技术见[前端架构](frontend.md)。

| 页面 | 采用的信息结构 | 约束与阶段 |
| --- | --- | --- |
| 全局总览 | 地区分布、主机摘要、关注事项、运行任务、近期活动 | 地图可收起；同一告警不在多个栏目重复堆叠；完整告警后续开放 |
| 主机列表 | 分组、筛选、搜索、紧凑列表、可选星图 | 列表为默认；星图表示分组，不表示真实网络连接 |
| Kubernetes | 资源标签、拓扑、选中对象详情 | MVP 后；区分归属、调度、选择与实际流量，不用装饰连线冒充依赖 |
| Docker | 当前主机、容器列表、日志、资源与镜像 | 列表优先；轨道仅表示归属；清理和部署按钮按实际能力开放 |
| 任务 | 阶段轨迹、逐目标状态、日志与尝试记录 | 展示真实步骤；无依据不显示剩余时间；状态待确认不能归为失败或成功 |
| Agent | 心跳、版本、能力、连接质量 | 在线与可升级为独立维度；在线率不是整体健康分；不重复建设全球地图 |
| 审计 | 时间线、筛选、右侧详情 | 风险、结果、审批分别展示；原始内容按权限脱敏 |
| 文件 | 目录树、预览/编辑区、属性与差异 | MVP 先预览传输；只读无保存动作；版本历史依赖真实快照记录 |

AI 是跨页面的核心入口：关联主机指标、选定容器日志、任务失败步骤或受授权文件差异。右侧对象详情与 AI 面板切换或共用空间，避免多个侧栏挤压工作区。分析固定目标和时间范围；运行任务不得随页面切换改变目标。

星图只负责可视化，管理操作放在标准详情与确认流程。请求流动动画需要实际遥测，不从资源清单推导网络调用。节点位置保持稳定，状态更新不使选中对象漂移；提供等价列表、键盘入口与减少动态模式。

参考图中的星球、天文台和星空不是必须上线的美术资产。首版以弧线、刻度和轻量轨迹建立辨识度；后续素材需明确来源、许可和本地资源位置，不直接依赖聊天临时图片路径。
