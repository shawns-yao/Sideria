更新日期：2026-10-06

本文维护技术职责、组件边界和数据流；视觉规则见 [UI 设计](ui.md)，其他页面的概念图取舍见[页面设计](pages.md)。

## 首个实现切片

先实现单服务器仪表台：应用导航、主机选择、CPU 开放弧线、Memory 空间用量、Disk 轨道尺度、Network 双向曲线、系统摘要，以及 AI/终端未接入状态。提供明确标记的演示数据，覆盖在线、失联和无数据。演示模式不发起远程调用，不生成假 AI 回答、不模拟命令成功。

该切片是前端基础，不代表 roadmap 阶段一完成。完成后再接中心认证、Agent 上报和真实数据；模拟数据不能成为生产请求失败时的回退结果。

| 层 | 首个切片 | 后续边界 |
| --- | --- | --- |
| 页面与组件 | Vue 3、TypeScript、Vite | Vue 单文件组件；不在一个页面堆入全部功能 |

| 图标 | @lucide/vue | 使用 Lucide 当前 Vue 包；旧 lucide-vue-next 已由 npm 标记弃用 |
| 路由与共享状态 | 首切片本地选中状态 | 多页面时引入路由；会话与服务端缓存分别管理 |
| 复杂图表 | 暂不引入 | ECharts 为候选，接入时复核版本及体积 |
| 终端 | 首切片展示未接入 | xterm.js 负责显示，中心/Agent 负责真实 PTY |
| 编辑与 Diff | 首切片不实现 | Monaco 为候选，版本历史由后端维护 |

## 组件与数据流

页面负责选择目标和协调面板；指标组件只接受数据与显示状态；格式化和曲线路径计算独立维护。演示数据单独位于 demo，不混在组件内。

生产阶段数据流为：中心响应/事件 → 运行时校验 → 按 Host ID 保存快照 → 页面选中目标 → 展示组件。TypeScript 类型不代替运行时校验。切换目标时取消旧请求或检查请求代次，迟到结果不得覆盖新主机；连接与订阅卸载时释放。

每个快照包含稳定目标 ID、采样/接收时间、连接状态及指标缺失信息。离线的旧值必须标明过期；无数据使用空值，不用 0。百分比明确范围，内存以总量和可用量定义首版占用；Available 不等于 Free。

API 客户端集中处理认证失败、权限拒绝、超时和取消；所有用户操作仍由中心校验。浏览器不保存模型 API Key、Agent 凭据或数据库地址。正式 HTTP API 尚未定义，演示模型不是最终线协议。

## 文件与构建

| 位置 | 用途与保留 |
| --- | --- |
| web/src/components | 可复用展示组件，提交 |
| web/src/demo | 明确标识的固定 UI 样本，提交；生产功能不依赖 |
| web/src/domain | 前端类型、格式化和展示计算，提交 |
| web/src/styles | 设计 Tokens 和布局，提交 |
| web/package.json、package-lock.json | 依赖与复现安装，提交 |
| web/node_modules | 安装产物，不提交 |
| web/dist | 可重建构建产物，生产嵌入中心前生成，不提交 |
| docs | 长期设计说明，提交 |

首切片无秘密配置、数据库迁移或真实运行数据。预览监听 127.0.0.1；不默认向局域网开放。后续 Go embed 的构建复制入口在中心工程建立时定义，不能只写 embed 声明而缺少产物。

计划命令在 web 目录执行：npm install、npm run typecheck、npm run build、npm run dev。实际执行结果在交付时报告；脚本存在不等于运行通过。
