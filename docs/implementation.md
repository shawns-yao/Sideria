## 技术决策

- 单 Workspace、单中心、Linux Agent。v1 JSON WebSocket，TLS 强制，唯一例外为显式开发模式的 loopback HTTP；协议版本不匹配拒绝。
- 管理员凭据仅环境注入；浏览器登录换 HttpOnly SameSite=Strict 会话。Agent 使用独立随机令牌，中心只存 SHA-256 摘要。注册令牌十分钟、一次性，重复连接拒绝。
- PostgreSQL 是身份、项目、任务、幂等、审计和分析事实源。写操作先落库后投递；相同任务始终重传同一个 Attempt。Agent 本地 journal 在副作用前 fsync，重启遗留 running 为 uncertain，不自动重做。
- 文件根通过 Go os.Root 限定；新增上传 O_EXCL，首版禁止覆盖。独立 HTTPS 传输、限大小和时间，中转临时文件有期限并受任务身份检查。终端单独显式能力授权，不向 AI 开放。
- Redis 故障拒绝新注册、工具、写任务和分析。租约仅协调，Agent 本地资源串行及执行 journal 决定是否可启动。
- 采样默认 5 秒，可逐 Agent 配置；样本携带间隔，界面过期与断线段阈值随实际配置变化；短窗口最多 360 样本，当前实现不承诺长期趋势或账单流量。CPU 温度无数据不填零。
- AI 默认关闭。中心显式配置提供方、模型、API Key 和外发开关后启用；只读工具目标必须在分析初始范围内。没有真实凭据不宣称真实验收通过。
- 开发验证仅隔离云内资源；双 Agent 不等于两台真实服务器验收。测试凭据仅进程环境/临时目录，结束清理。

隔离验证不替代以下列出的真实环境验收。

## 性能与资源基线

环境：Linux amd64 云容器，Go 1.27.1、可用 5 CPU，报告 CPU 型号 AMD EPYC 9V74；中心/PostgreSQL 17/Redis 7/两个本地 Agent 同一云环境。此条件不能推算真实服务器容量。

- `go test ./internal/agent -run '^$' -bench BenchmarkSampler -benchmem -count=3`：每次完整采样 212568 / 228301 / 243623 ns，约 94848 B、1084 allocations。默认采样 5 秒，不承诺跨平台固定耗时。
- 故障恢复后诊断快照：2 Agent、76 短窗口样本、0 活动查询/终端，中心 Go heap 1689296 bytes、11 goroutines、2 DB connections。这是瞬时快照，不是 RSS 或长期稳定性结论。
- 前端当前构建入口约 209 KB（gzip 70 KB），xterm 独立按需加载约 334 KB（gzip 84 KB）。不在仪表台初始入口加载终端。
- 当前优先修复已测得的租约延迟。大目录、并发文件、长期采样、较多主机及公网延迟仍需专项容量测试，不能称为企业规模验证完成。

## 保留与容量边界

- 短窗口每主机最多 360 样本；中心重启后窗口重新累积，最新快照持久化。缺口不补零；长期时序聚合明确后置。
- 当前单文件 32 MiB、中心同时 2 个入站传输，spool 约 512 MiB 限额，完成或遗留文件 1 小时后清理。完整大文件断点续传尚未实现。
- 会话 8 小时；过期会话每分钟清理；分析（脱敏、预算内证据）保留 30 天，审计与已完成任务/幂等记录保留 90 天。未确认任务不自动删除。
- Agent journal 在约 64 MiB 或 100000 次执行记录时停止受理新写操作，已有记录仍用于查重；不自动删除不确定记录。维护前须保留审计和完成事实。
- 每主机最多 100 个活动任务，查询全局 64 并发，终端全局/Agent 各 8，会话最长 1 小时，浏览器空闲 15 分钟关闭连接；日志/预览 64 KiB。
- AI 同时 2 次分析、每次 2 分钟、最多 5 轮/8 次工具调用，单结果 24 KiB、总请求 128 KiB、每轮输出 2048 tokens。供应商费用需按实际模型验证。
